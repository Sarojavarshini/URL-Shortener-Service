# LinkLite — URL Shortener Service

A Java 17 + Spring Boot + MySQL internship project that shortens long URLs, redirects users, records clicks, and displays a simple analytics dashboard.

## Features

- Generates unique 7-character short codes.
- Validates that submitted URLs use `http://` or `https://`.
- Redirects short links to their original destinations.
- Records total clicks and click timestamps.
- Shows total links, total clicks, a link table, and per-link daily click analytics.
- REST API with JSON responses.
- Stores click time, referrer, and user-agent; it does **not** store visitor IP addresses.

## Technology stack

- Java 17
- Spring Boot 3.4.5
- Spring Web / REST
- Spring Data JPA / Hibernate
- MySQL 8+
- Maven
- HTML, CSS, and JavaScript dashboard

## Setup on Windows

### 1. Create the MySQL database

Open MySQL Workbench or the MySQL command line and run:

```sql
CREATE DATABASE url_shortener_db;
```

### 2. Configure database credentials

Open `src/main/resources/application.properties`.

The default username is `root` and the password placeholder is `change_me`. Replace it with your local MySQL password, or set environment variables before running:

**PowerShell**
```powershell
$env:DB_USERNAME="root"
$env:DB_PASSWORD="your_mysql_password"
```

Do not commit real passwords to GitHub. For a public deployment, use environment variables or a secrets manager.

### 3. Run the project

From the project root (the folder containing `pom.xml`):

```powershell
mvn spring-boot:run
```

If the `mvn` command is not recognized, install Maven or run the project using the Maven wrapper generated by your IDE. On successful startup, open:

- Dashboard: http://localhost:8080/
- API base: http://localhost:8080/api

Hibernate creates/updates the tables automatically in development mode.

## REST API

### Create a short URL

`POST /api/urls`

Request:
```json
{
  "url": "https://www.example.com/articles/java/spring-boot"
}
```

Example response:
```json
{
  "id": 1,
  "originalUrl": "https://www.example.com/articles/java/spring-boot",
  "shortCode": "aB3xY7p",
  "shortUrl": "http://localhost:8080/aB3xY7p",
  "clicks": 0,
  "createdAt": "2026-10-20T12:00:00"
}
```

The short code in this example is illustrative; the application generates a new code.

### Redirect and record a click

Open `GET /{shortCode}` in a browser. The service returns HTTP `302 Found`, increments the click count, stores a click event, and redirects to the destination.

### List all links

`GET /api/urls`

### Analytics for one short link

`GET /api/urls/{shortCode}/analytics`

Returns the total clicks and daily click counts.

### Overall summary

`GET /api/analytics/summary`

Example:
```json
{
  "totalUrls": 3,
  "totalClicks": 25
}
```

## Test with PowerShell

Create a link:
```powershell
Invoke-RestMethod -Method Post -Uri "http://localhost:8080/api/urls" -ContentType "application/json" -Body '{"url":"https://spring.io"}'
```

List links:
```powershell
Invoke-RestMethod -Uri "http://localhost:8080/api/urls"
```

Summary:
```powershell
Invoke-RestMethod -Uri "http://localhost:8080/api/analytics/summary"
```

Use the `shortCode` returned from the create response to open the redirect URL and then call its analytics endpoint.

## Database tables

- `url_mappings`: original URL, unique short code, creation time, total click count.
- `click_events`: each click timestamp, optional referrer and user-agent, and the associated URL record.
